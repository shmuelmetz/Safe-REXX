# Safe-REXX

Merged and updated edition of *Safe REXX on the Desktop* (1993/1995)
and *Safe REXX in the Enterprise* (1993/2023) by Shmuel (Seymour J.) Metz.

Scope: classic Rexx, ooRexx, TSO/E, ISPF, OMVS, System REXX, CMS,
OS/2, Linux, Windows, ArcaOS.

## Status

`Safe-REXX-Merged-DRAFT.md` is a first structural draft of the merged
edition — see its own header comment for exactly what's done (full
merge of both source papers, ooRexx guidance grounded in
`AI-Priming/ooRexx/RULES.md`) and what's still pending (dedicated
ISPF, System REXX, and fuller ArcaOS/OREXX sections). The original
source files, in several formats and archival copies from both
publication venues, remain in this repo's subdirectories
(`NASPA/`, `OS2DEV/`, `Attached/`, `TSM/`, `$REXX/`, `Safe REXX/`) for
provenance — see the draft's header comment for which copies are
correctly labeled (a real filename trap exists: `NASPA/SAFEREXX.*` is
actually the *Enterprise* paper despite the filename, not Desktop).
